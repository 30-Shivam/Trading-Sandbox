# llm_research -- free-data fundamentals + blind-LLM test (2026-10-23)
Pipeline (all free: SEC EDGAR companyfacts as-filed + Yahoo prices + hanshof point-in-time S&P 500 membership):
1. `python llm_research/build_dataset.py` -> cache/dataset.pkl, prices.pkl (4,781 10-K filings, 394 tickers, 2010-2025, label = 126d return vs SPY)
2. `python llm_research/baseline.py` -> per-feature IC + walk-forward ridge (the non-LLM control)
3. `python llm_research/portfolio_test.py` -> causal walk-forward daily portfolio vs SPY (labels must have ended before the test year)
4. LLM arm: anonymized ratio batches (cache/batches), scored 1-9 by blind subagents (cache/scores), `python llm_research/evaluate_llm.py`
cache/ is gitignored and regenerated by step 1.
Caveats: only names resolvable to a CIK and priced on Yahoo (76% of point-in-time members): survivor-tilted, though the all-filings base rate is -0.4% vs SPY.
